# Twitch !qr → оверлей с превью Telegram-поста и QR-кодом

По команде `!qr <ссылка на t.me>` в чате Twitch в OBS появляется карточка:
слева — стилизованная под Telegram карточка поста (аватар, название канала,
число подписчиков, фото, текст, реакции, просмотры, «Прокомментировать»),
справа — QR-код с круглой аватаркой канала в центре и лёгкой подсветкой.
Если пост не помещается в карточку целиком — она автоматически плавно
прокручивается вниз, пока показана (зритель не может скроллить статичный
оверлей сам). Обе карточки появляются и уезжают снизу, слегка покачиваясь,
пока на экране. Через несколько секунд оверлей сам прячется.

## Как это устроено

- `index.js` — один процесс: Twitch-бот (tmi.js) + локальный сервер
  (Express + WebSocket).
- `lib/telegram.js` — парсит публичную embed-версию поста (фото, текст,
  просмотры, реакции, аватар, число подписчиков), либо находит последний
  пост канала через публичную ленту `t.me/s/<channel>`. Работает только с
  **публичными** каналами и постами, без Bot API и логина.
- `public/overlay.html` — страница, которую вы добавляете в OBS как
  **Browser Source**. Слушает WebSocket и рисует карточку + QR (через
  библиотеку `qr-code-styling`).

## Установка

Нужен установленный [Node.js](https://nodejs.org) (18+).

```bash
cd twitch-tg-qr-overlay
npm install
cp .env.example .env
```

Откройте `.env` и заполните:

- `TWITCH_BOT_USERNAME` — имя аккаунта бота (можно использовать аккаунт
  стримера).
- `TWITCH_OAUTH_TOKEN` — токен, получить тут:
  https://twitchapps.com/tmi/ (войти под аккаунтом бота, скопировать
  значение вида `oauth:xxxxxxxx`).
- `TWITCH_CHANNEL` — канал, в чат которого подключаемся (без `#`).
- `QR_COMMAND_PERMISSION` — кто может вызывать команду: `everyone`,
  `mods` (по умолчанию) или `broadcaster`.
- `QR_COMMAND_COOLDOWN` — антиспам кулдаун в секундах.
- `OVERLAY_DISPLAY_SECONDS` — сколько секунд карточка видна на экране
  (если пост длинный и надо больше времени на прокрутку — оверлей сам
  покажет его чуть дольше этого значения).

## Запуск

```bash
npm start
```

В консоли появится:

```
[server] Оверлей доступен по адресу http://localhost:8123/overlay.html
[twitch] Подключён к каналу #your_channel
```

## Добавление в OBS

1. Источники → **+** → **Браузер (Browser Source)**.
2. URL: `http://localhost:8123/overlay.html`
3. Ширина/высота: например `1920x1080` (страница сама центрирует карточку,
   фон прозрачный).
4. **Важно:** в свойствах источника должен быть включён доступ в интернет
   (по умолчанию так и есть) — виджет Telegram грузится с `telegram.org`
   и требует реального сетевого запроса из браузера OBS, локальным файлом
   не обойтись.

В чате:

```
!qr https://t.me/your_channel
```

— бот сам найдёт **последний пост** в канале и покажет его превью.
Можно также указать конкретный пост явно:

```
!qr https://t.me/your_channel/123
```

и карточка с QR появится в OBS.

## Важные нюансы

- **Только публичные каналы/посты.** Приватные ссылки (`t.me/c/...`)
  через эту схему превью не получить — для них нужен полноценный
  Telegram Bot API и доступ бота в канал, это отдельная история.
- **Разметка t.me может меняться.** Парсер в `lib/telegram.js` собран
  по текущей структуре embed-страницы Telegram. Если в какой-то момент
  Telegram поменяет вёрстку и парсинг перестанет находить фото/реакции/
  подписчиков — поправить нужно именно там (селекторы `tgme_widget_message_*`
  и `tgme_page_extra`). Сама карточка в оверлее гибкая: если каких-то
  данных нет, соответствующий блок просто не отрисуется.
- Видео и закреплённые сообщения канала (то, что видно только внутри
  самого приложения Telegram) через публичный парсинг недоступны —
  карточка показывает фото, текст, реакции, просмотры и подписчиков.
- Если пост не найден вообще (пустой/недоступный канал), в тексте карточки
  показывается причина, а QR всё равно ведёт на сам канал.
- QR-код всегда ведёт на **сам канал** (`t.me/username`), а не на
  конкретный пост — аватар в центре QR автоматически обрезается в круг.
- Все цвета и форма QR (скруглённые точки, свечение, подсветка) настраиваются
  в `public/overlay.html` в вызове `new QRCodeStyling({...})`.

## Возможные доработки

- Очередь команд, если несколько зрителей подряд вызовут `!qr`.
- Звук при появлении карточки (добавить `<audio>` в overlay.html).
- Канал-вайтлист: показывать карточку только для ссылок на свой канал,
  чтобы зрители не могли рекламировать чужие через бота.
